| **2** | [Predicting Academic Success: A ML Approach Using Decision Tables and Random Forests](https://doi.org/10.5281/zenodo.15380415) | *Spectrum of Engineering Sciences*, 3(5), 205–213 (2025) | Co-author |

<details>
<summary><b>What these papers actually did</b></summary>

<br/>

**Cardiovascular Risk Prediction** — Benchmarked SVM, Gradient Boosting and Rotation Forest in Python/scikit-learn on a 1,025-record, 14-feature clinical dataset. Evaluated with accuracy, precision, recall, F1 and confusion-matrix analysis, with the discussion framed around the clinical cost of false negatives. The ensemble methods substantially outperformed SVM (64.9% accuracy).

**Predicting Academic Success** — Used best-first search feature selection to reduce a 33-attribute, 395-instance UCI student-performance dataset down to 11 attributes, then compared Decision Tables against Random Forests on correlation coefficient, RMSE and MAE. The interpretable Decision Table achieved the lower error (RMSE 1.92 vs 1.99) — a useful result for institutions without in-house ML expertise.

</details>
